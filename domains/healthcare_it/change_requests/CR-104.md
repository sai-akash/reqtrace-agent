# CR-104: Pharmacy dispensing cabinet integration

**Fictional document for testing.**

## 1. Summary

Connect the pharmacy order system to a new dispensing cabinet so that approved orders appear at the cabinet automatically.

## 2. System

System: Pharmacy Order System. Classification: Tier 1. This is not an emergency change.

## 3. Schedule

Deployment is planned for Sunday 15 November 2026, from 01:30 to 03:30 local time.

## 4. Testing

Tested in the STAGING-PHARM environment on 28 October 2026. Outcome: all 31 test scenarios passed.

Test data was taken from the pharmacy system.

## 5. Rollback

The rollback plan will be written after deployment.

## 6. Approvals

Change Advisory Board approved on 3 November 2026.

## 7. Vendor involvement

The cabinet vendor will connect remotely using MFA. Access is limited to 48 hours.

## 8. Interfaces

This change adds an interface between the pharmacy system and the cabinet. The interface will use TLS 1.0 because of the current cabinet firmware.

## 9. Database

This change adds two tables to the pharmacy database. A verified backup is scheduled for Saturday 14 November 2026 at 20:00 local time.
